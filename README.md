
## how to
- provide the prompts `from hvibe-v0.2.2/prompt-generate-project.hvibe.txt` to your LLM
- then provide the `hvibe-v0.2.2/voxy-trip.hvibe` content to the same LLM

## Run the generated output
```bash
python3 -m http.server 8080 --directory ./
```

Then navigate to http://localhost:8080 in your browser.
